# The Unfound

SEO, GEO, AI GEO, and lead generation in one growth OS.

## What it is

**The Unfound** helps teams:

- Track and grow organic search (SEO)
- Win local / map visibility (GEO)
- Monitor citations across AI answer engines (AI GEO)
- Capture and score high-intent leads from those channels

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## App routes

| Route | Purpose |
| --- | --- |
| `/` | Marketing landing |
| `/pricing` | Plans |
| `/dashboard` | Growth overview |
| `/dashboard/seo` | Keyword & cluster engine |
| `/dashboard/geo` | GEO + AI GEO citations |
| `/dashboard/leads` | Lead inbox & scoring |
| `/dashboard/opportunities` | Prioritized actions |

Demo data lives in `src/lib/demo-data.ts`.
